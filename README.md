
# Customer Feedback - Pollution Reporting System

## About the Project

Customer Feedback is a web-based pollution reporting
system developed using Google Apps Script.

It allows customers to submit pollution complaints,
provide their contact details, and upload multiple images.

All feedback records are automatically stored in
Google Sheets, while uploaded images are stored in
Google Drive.

## Features

- Customer name and mobile number collection
- Pollution category selection
- Pollution complaint description
- Multiple image uploads
- Automatic Google Drive image storage
- Google Sheets data management
- Unique feedback ID generation
- Responsive user interface

## Technologies Used

- JavaScript
- HTML5
- CSS3
- Google Apps Script
- Google Sheets
- Google Drive

## Setup Instructions

1. Open Google Apps Script.
2. Create a new project.
3. Copy Code.gs into the script editor.
4. Create an HTML file named Index.
5. Paste the Index.html code.
6. Run setupProject().
7. Authorize Google Drive and Sheets access.
8. Deploy as a Web App.

## Storage

Google Sheets: Customer feedback records.

Google Drive: Uploaded pollution images.
